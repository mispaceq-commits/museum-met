# The Writer's Collective &mdash; Met Edition

A digital literary gallery hero, with a 3D auto-rotating orbit of paintings
swirling around a central THE MET pillar mark.

Static site &mdash; just open `index.html` in a modern browser.

## Files

- `index.html` &mdash; markup (navbar, hero copy, 3D carousel, footer grid)
- `styles.css` &mdash; visual design + 3D carousel geometry
- `script.js` &mdash; (small) hover-pause + caption hover behaviour
- `logo.svg` &mdash; THE MET pillar mark (center of the orbit)
